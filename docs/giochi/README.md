# Diari dei giochi

Un file per gioco, `<id>.md`, scritto e aggiornato dalla chat di quel gioco (dal gioco 3 in poi):
stato, cosa c'è nel gioco, link alla pagina di prova, cosa provare sul telefono, richieste per la regia.

Il diario dei giochi 1 e 2 è nel registro di `docs/03-ROADMAP.md`. La tabella di stato in quel file la aggiorna la regia.
