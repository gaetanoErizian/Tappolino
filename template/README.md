# template/ — codice comune dei giochi Tappolino

`core/` è nato con il gioco 1 (*Pompieri in Azione*) e va copiato **identico** in `src/core/` di ogni nuovo gioco.
Istruzioni complete, file di supporto (main.ts, app.ts, Boot, vite/capacitor config) e lezioni apprese: `docs/04-TEMPLATE.md` (copia del doc di progetto) e `games/pompieri-in-azione/README.md`.
